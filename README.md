# Semester 4 Finals Dashboard 🚀

An ultimate, automated study dashboard featuring interactive AI flashcards, Pomodoro focus timers, Master Summaries, Code Vaults, and categorized study materials for Semester 4 finals.

👉 **[Click here to open the Live Dashboard](https://MAGDY0-0-0.github.io/sem4/)** 👈

## Features
- **Smart Categorization:** Automatically groups local files into Lectures, Problem Sheets, and Other Materials.
- **Deep Focus:** Integrated Pomodoro timer with audible alerts and session tracking, plus a "Zen Mode" toggle for distraction-free reading.
- **Mock Exams:** Practice tests with instant grading logic.
- **Interactive Flashcards:** Tap to flip and reveal expert answers for Computer Architecture, Software Engineering, etc.
